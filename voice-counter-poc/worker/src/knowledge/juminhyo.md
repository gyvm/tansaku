# 住民票の写しの交付（ダミー情報）

- 窓口: 市役所本庁舎1階 市民課（3番窓口）、または各支所。平日8時30分〜17時15分。
- 必要なもの: 本人確認書類（マイナンバーカード、運転免許証など）。代理人の場合は委任状も必要。
- 手数料: 1通300円。
- コンビニ交付: マイナンバーカードがあれば、全国のコンビニで6時30分〜23時に取得可能。手数料は1通200円。
- 郵送請求: 請求書、本人確認書類のコピー、定額小為替、返信用封筒を市民課へ送付。届くまで1週間程度。
- マイナンバー（個人番号）入りの写しは、原則として本人または同一世帯の方のみ請求できる。
