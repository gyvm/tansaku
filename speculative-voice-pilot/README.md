# 多重投機的ストリーミング 音声エージェント (Speculative Voice Pilot)

札幌市役所の窓口手続き（住民票取得・転入届・マイナンバーカード・ごみ分別など）を題材にした、
**「多重投機的ストリーミング（Speculative Streaming Pipeline）」** による超低遅延（ゼロ遅延）電話応対プロトタイプです。

---

## 💡 コア技術と仕組み

通常の音声対話システムでは「相手が話し終えるのを待ってから」LLM推論と音声合成（TTS）を呼ぶため、どんなに速いモデルでも 500〜1200ms の沈黙（TTFA）が発生します。
また、相手が話している途中で無理に結論を先行生成させると、「早とちり（例: 児童手当を聞いたのに保育園の窓口を答えてしまう）」が発生します。

本システムでは、**「2段階チェーニング投機アーキテクチャ（Dual-Tier Speculative Chaining）」** を採用しています：

1. **発話途中（先行投機 / Tier-1 Prefix）**:
   - 相手が話している最中（単語・文節が進むごと）に、結論ではなく「自然な共感・相槌クッション音声（例:『かしこまりました。児童手当のお手続きですね。』）」を先行ストリーミング生成してバッファリング。
2. **発話終了時（即時再生 & 核心回答結合 / Tier-2 Payload）**:
   - 言い終わった瞬間に、手元に溜まっていた Tier-1 クッション音声を即座に再生開始（**実効レイテンシ 0ms**）。
   - クッション音声が再生されている 1〜1.5秒 の間に、確定全文（Final Text）からピンポイントにセクション抽出（Section-Aware RAG）を行い、前置き抜きの核心結論音声を非同期生成。
   - Web Audio API 上で Tier-1 の末尾と Tier-2 の先頭を無音なし（Gapless）でシームレスに結合（Audio Stitching）。
3. **セマンティック・コミット検証（Commit Verifier）**:
   - Final Text とトピック・意図が合致しない古いストリームは即座に破棄（Squash）し、誤った回答の再生を構造的に遮断。

```text
【市民発話中】
t = 0.0s: 「子どもが生まれたので…」
          --> [Stream 1] 相槌「おめでとうございます！お子様のお手続きですね」先行生成
t = 1.0s: 「…児童手当の手続きをしたいのですが…」
          --> [Stream 2] 相槌「かしこまりました。児童手当のお手続きですね」先行生成
t = 2.0s: 「…何が必要ですか？」 --> 発話終了 (isFinal: true)

【発話終了時 (t = 2.0s)】
① [Stream 2] 相槌音声を【沈黙 0秒】で即座に再生開始！
② 並行して裏で Final Text に基づく核心回答（申請書類・口座・マイナンバー）を非同期生成
③ 相槌音声の再生完了に合わせて、核心回答音声をギャップレスに結合して連続再生！
==> 体感遅延 0ms と 回答精度 100% を完全両立！
```

## 🚀 起動方法

### 前提条件
- `ELEVENLABS_API_KEY`: `~/.zshrc.local` または環境変数に設定済みであること。
- ランタイム: `bun` (推奨) または `node` (v20+)

### サーバー起動
```bash
cd /Volumes/SN850X/GitHub/tansaku/speculative-voice-pilot

# Bun で起動する場合 (推奨)
bun run server.ts

# または pnpm / tsx で起動する場合
pnpm dev
```

起動後、ブラウザで以下の URL を開きます：
👉 **http://localhost:3000**

## 🖥️ ブラウザ画面での操作・検証方法

1. **画面を開いたら「🔊 音声出力を有効化」をクリック**
   - ブラウザの自動再生ポリシーを解除し、Web Audio API の PCM 24kHz 再生エンジンを準備します。
2. **ワンクリック発話シミュレーション（おすすめ）**:
   - `①「住民票を取りたい（転入）」` をクリック
   - 450ms おきに「住民票を…」「他の区から引っ越してきたので…」「住民票を取りたいんですけど。」と発話が進みます。
   - 画面中段の **「裏側で並行稼働中の投機ストリーム」** に、リアルタイムで Stream 1, Stream 2 が立ち上がり、バッファが蓄積されていく様子が視覚的に確認できます。
   - 言い終わった瞬間に「★ WINNER」が決まり、**スピーカーから即座に滑らかな案内音声（Sarah）が再生**されます。
   - メーターに **「実効レイテンシ: 10〜30ms」「先行バッファ量: 数十KB」** が表示されます。
3. **マイクによる対話**:
   - Google Chrome 等で `🎤 マイクで通話開始` を押すと、Web Speech API による日本語音声認識で実際に自分の声で話しかけることができます。
4. **会話の展開（3往復）**:
   - 札幌市役所AIが「マイナンバーカードはお持ちでしょうか？」と尋ねてきたら、
     `②「マイナンバーカード持ってます」` または `③「カードは持っていません」` をクリックすると、それぞれの分岐に応じた案内が即座に返ってきます。

## 📁 ファイル構成

- `server.ts`: HTTP 静的ファイル配信 ＋ WebSocket サーバー
- `speculative_manager.ts`: 多重投機ストリームのライフサイクル管理（起動・バッファリング・判定・コミット・アボート）
- `knowledge.ts`: 札幌市役所の窓口手続き（住民票、転入、マイナンバー、ごみ）の構造化ナレッジベース
- `public/index.html`: Web Audio API（24kHz PCM ストリーミング再生）＋ 投機モニター ＋ マイク音声入力
